# Формат profile (версия 2)

profile — текстовый файл, который пишет builder (`builder/qmem-build.py`) и исполняет replay (`replay/qmem-replay`). Одна запись на строку: `тип ключ=значение ...`. Пустые строки и всё после `#` пропускаются.

## Пример

```
qmem-profile 2
meta source=rec1 builder=2 intensity=passthrough timing=roundrobin write=softdirty
meta epoch_ms=100

region id=0 size=67108864 kind=anon base=0x7f0000000000
map t=500 region=0 off=0 len=67108864
populate t=500 region=0 off=0 len=67108864

epoch t=1000 dur=100
access region=0 off=0 len=16777216 rate=200 write=0.5 pattern=roundrobin

unmap t=2500 region=0 off=0 len=33554432
counter t=1000 name=pmu.loads value=0
```

## Совместимость

- **Версия.** Первая строка — `qmem-profile <старшая версия>`. Старшая версия меняется только при несовместимых изменениях.
- **Неизвестный ключ** replay пропускает. **Неизвестный тип строки** — тоже, с одним предупреждением на тип.
- **Ключ с `!`** (`!foo=1`) — обязательный для понимания: если replay его не знает, он отказывается работать (код 2). Знакомый ключ пишется с `!` или без — смысл одинаковый.
- **Ошибки** (нет обязательного ключа, неверное значение, время назад) — код 2 и `profile:<строка>: ...`.

## Типы строк

| Тип | Обязательные ключи | Необязательные | Смысл |
| --- | --- | --- | --- |
| `meta` | — | `epoch_ms` (по умолчанию 100), любые другие | Параметры и сведения о происхождении. replay использует только `epoch_ms` |
| `region` | `id`, `size` | `kind` (`anon` по умолчанию; `file` — заглушка, replay откажется), `base` (адрес в оригинале, hex), `file` | Регион памяти. `id` — 0, 1, 2, ... по порядку |
| `map` / `unmap` / `populate` | `t`, `region`, `off`, `len` | — | Выделить, освободить или один раз записать каждую страницу участка. `off`, `len` кратны странице. Времена этих строк не убывают |
| `epoch` | `t` | `dur` (по умолчанию `epoch_ms`) | Эпоха с `t` по `t + dur`; следующие строки `access` относятся к ней. Времена эпох растут |
| `access` | `region`, `off`, `len`, `rate` | `write` (0..1, по умолчанию 0), `pattern` (`roundrobin` по умолчанию, `random`, `poisson` — заглушка), `threads` (заглушка, по умолчанию 1) | Обращения эпохи к участку. **`rate` — касаний на одну страницу в секунду**, replay умножает на число страниц участка |
| `counter` | `t`, `name`, `value` | — | Числовой ряд для будущих оценщиков и режимов. Сейчас replay его не использует |

Время `t`, `dur` — миллисекунды от начала сценария. Размеры и смещения — байты.

## Заглушки

| Где | Поведение сейчас |
| --- | --- |
| `pattern=random` | Случайная равновероятная страница участка |
| `pattern=poisson` | Как `random`; одно предупреждение |
| `threads=N`, N > 1 | Один поток; одно предупреждение |
| `kind=file` | replay отказывается: `file regions are not supported yet` |
| `counter` | Принимается и пропускается |
