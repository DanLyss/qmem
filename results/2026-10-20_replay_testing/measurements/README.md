# Измерения: replay против memtest (damoLoad) на 101 конфиге

2026-10-20 · `make damoload-check` · коммит `48ac2bc` · WSL2, ядро 6.18, damoLoad `83763e9`

## Что измерялось

Каждый конфиг из `third_party/damoLoad/memtest/configs/` на полную длительность (10–60 с, всего около 40 минут):

1. memtest исполняет конфиг и пишет каждое обращение (`gt.log`). Это эталон.
2. `tools/memtest2profile.py` переводит тот же конфиг в profile.
3. `qmem-replay --log-level touches` исполняет profile и пишет каждое касание.
4. `tools/damoload_check.py` сводит оба лога к таблице «регион × окно 100 мс × страница» и сравнивает:

| Проверка | Порог | Что ловит |
| --- | --- | --- |
| Сумма по региону в окне | `\|replay − memtest\| ≤ 4√memtest + 2` | Не то время: касания раньше или позже |
| Распределение по страницам за прогон | расстояние полной вариации ≤ 0.05 + 3 × ожидаемый шум | Не те страницы |
| Общее число касаний | ≤ 2% + 4√memtest | Не тот объём |

Конфиг совпал, если прошли все три проверки.

## Почему не совпали 7 конфигов

| Конфиг | Причина |
| --- | --- |
| `101_5500reg_realistic_app` | **Ошибка replay:** выделение и заполнение 5500 регионов в момент 0 занимает сотни миллисекунд, после чего опоздавшие тики выполняются подряд, а не бросаются. Плюс memtest сам не успевает на 5500 потоках |
| `82_100reg_sub_aggr_bursts` | **memtest:** когда трек молчит, memtest обнуляет накопленную работу. Всплески здесь короче его интервала, и он делает 18 касаний вместо 2000 по собственному конфигу. replay исполняет конфиг |
| `77_100reg_all_pages_burst` | **memtest:** в начале каждого включения опаздывает на интервал (20 мс), касания переезжают в соседнее окно |
| `80_100reg_3layer` | **memtest:** то же, малые числа в окне (2 против 10) |
| `88_100reg_dominance_swap` | **memtest:** при скачке частоты с 5 до 200 Гц сначала досыпает интервал под старую частоту (до 200 мс). Первое окно после скачка пустое |
| `100_ultimate_100reg_chaos` | Очень низкие частоты, ожидание меньше 1 касания в окне. Строки profile по страницам дозревают одновременно, касания приходят пачкой (3–4 вместо 0–1) |
| `89_200reg_mixed_random` | То же, одно окно из 40 000 |
